# 急跌反弹机会捕获需求文档

> 基于 EVAAUSDT 2026-07-12 实际案例分析：8:00 单小时暴跌 -78.76%（$1.88→$0.40），随后反弹至 $1.32（4.4 倍）。系统因整点推送延迟（1h）+ 背离信号未利用 + 推送未高亮，错过最佳入场窗口。

---

## P1-1：大户 vs 散户多空比背离检测

### 背景

EVAAUSDT 暴跌后数据显示：
- 大户多空比 1.03-1.07（偏多）→ 大户在抄底
- 全网多空比 0.65-0.97 且持续下降（偏空）→ 散户在疯狂做空

这种"大户偏多 + 散户偏空"的背离是经典反弹信号，但当前 [computeMarketOutlook](file:///e:/code/BinaceSmart-main/smart-trend-monitor.mjs#L551) 只统计多空比变化方向，未捕捉此背离。

### 需求描述

在 `computeMarketOutlook` 及单币种决策中增加大户与散户多空比背离检测，当背离达到阈值时作为反弹信号加分项。

### 触发条件

```
背离度 = 大户多空比 - 全网多空比

当 背离度 ≥ 0.25 且 大户多空比 > 1.0 且 全网多空比 < 0.9
  → 判定为 "大户抄底/散户恐慌" 背离信号
  → rebound_watch 信号强度 +1 档
```

阈值 `0.25` 可通过环境变量 `SMART_TREND_DIVERGENCE_THRESHOLD` 配置，默认 0.25。

### 数据来源

| 指标 | API | 字段 |
|------|-----|------|
| 大户多空比 | `/futures/data/topLongShortPositionRatio` | `longShortRatio` |
| 全网多空比 | `/futures/data/globalLongShortAccountRatio` | `longShortRatio` |

### 涉及文件

| 文件 | 改动 |
|------|------|
| `smart-trend-monitor.mjs` | `scanSymbolForDigest` 增加获取全网多空比；`computeMarketOutlook` 增加背离统计 |
| `smart-trend-decision.mjs` | `classifyView` 中 rebound_watch 判定增加背离条件分支；`calcScore` 背离信号加分 |
| `smart-trend-labels.mjs` | 新增 `formatDivergence` 格式化函数；`DIGEST_TABLE_COLUMNS` 增加"背离"列 |

### 输出格式

**总体研判卡片** 增加背离统计段落：

```markdown
**📊 大户 vs 散户背离**
1. 背离信号 **3** 个 · 大户偏多+散户偏空
2. 最显著: EVAA 大户1.07 vs 散户0.65 (背离0.42)
```

**榜单表格** 增加"背离"列，显示 `+0.42` 红色标注（散户做空被大户抄底的标的）。

### 验收标准

- [ ] EVAAUSDT 在 9:00 推送时，背离列显示 `+0.42` 红色标注
- [ ] 总体研判卡片包含背离统计段落
- [ ] 背离度可通过 `SMART_TREND_DIVERGENCE_THRESHOLD` 环境变量配置
- [ ] 无全网多空比数据的币种，背离列显示 `-` 不报错

## P1-2：rebound_watch 信号单独高亮推送

### 背景

9:00 推送中 EVAAUSDT 可能已被判定为 rebound_watch，但淹没在 30+ 个币种的表格中，用户未注意到。需要一个独立的"急跌反弹观察"高亮区块。

### 需求描述

在 smart-trend 推送卡片中，当决策引擎输出 rebound_watch 信号且跌幅超过阈值时，在卡片顶部（固定监控板块之前）单独高亮展示，不让它被表格淹没。

### 触发条件

```
当 decision 输出的 action 组中包含 rebound_watch 视图
  且 该币种 |change24h| ≥ 15%
  → 在推送卡片顶部插入 "⚡ 急跌反弹观察" 独立高亮区块
```

跌幅阈值 `REBOUND_HIGHLIGHT_CHANGE_PCT` 可通过环境变量配置，默认 15。

### 涉及文件

| 文件 | 改动 |
|------|------|
| `smart-trend-monitor.mjs` | `buildMergedSmartTrendElements` 在固定监控板块之前插入反弹高亮区块 |
| `smart-trend-decision.mjs` | `buildSmartTrendDecision` 输出中增加 `reboundHighlights` 字段供 monitor 消费 |
| `smart-trend-labels.mjs` | 新增 `buildReboundHighlightElements` 格式化函数 |

### 输出格式

在推送卡片**顶部**（时间标题之后、固定监控之前）插入：

```markdown
**⚡ 急跌反弹观察 · 2 个**

1. **EVAA** 跌-78.8% → 反弹中(现$0.62) · 聪明钱偏多(1.15) · 大户抄底背离+0.42 · _先等价格确认_
2. **XXX** 跌-22.3% → 反弹中(现$X) · 聪明钱偏多(1.XX) · _先等价格确认_
```

使用红色/橙色模板突出显示，与普通表格视觉区分。

### 验收标准

- [ ] EVAAUSDT 在 9:00 推送时，出现在卡片顶部的"急跌反弹观察"高亮区块
- [ ] 高亮区块位于时间标题之后、固定监控板块之前
- [ ] 仅跌幅 ≥15% 的 rebound_watch 才进高亮区块，避免噪声
- [ ] 无符合条件币种时不显示该区块

## P2：暴跌推送增加反弹潜力评分

### 背景

当前 [runDumpAlertPush](file:///e:/code/BinaceSmart-main/server.mjs#L1216) 的暴跌推送定位是"风险预警"——告诉用户远离暴跌币。但暴跌后往往存在反弹机会，需要区分"该逃的"和"可观察反弹的"。

注意：当前 `DUMP_PUSH_ENABLED=false`，此需求需在开启暴跌推送后生效。

### 需求描述

在 [scan-dump-risk.mjs](file:///e:/code/BinaceSmart-main/scan-dump-risk.mjs) 的风险评分基础上，增加"反弹潜力评分"维度，在暴跌推送中同时展示风险分和反弹潜力分。

### 反弹潜力评分模型

```
反弹潜力分 = 0~100，由以下因子加权：

| 因子 | 条件 | 加分 | 数据来源 |
|------|------|------|---------|
| RSI6 超卖 | RSI6 < 20 | +25 | 1h K线计算 |
| RSI6 偏低 | RSI6 < 30 | +15 | 1h K线计算 |
| 跌幅深度 | 24h跌幅 ≤ -30% | +20 | ticker |
| 跌幅深度 | 24h跌幅 ≤ -50% | +30 | ticker |
| 大户偏多 | 大户多空比 > 1.0 | +15 | topLongShortPositionRatio |
| 散户偏空 | 全网多空比 < 0.8 | +10 | globalLongShortAccountRatio |
| 大户散户背离 | 背离度 ≥ 0.25 | +15 | 上述两者之差 |
| 缩量止跌 | 最近1h成交量 < 前3h均值50% | +10 | 1h K线 |
| 下影线长 | (收盘-最低)/(最高-最低) < 0.3 | +10 | 1h K线 |
```

### 反弹潜力等级

| 分数 | 等级 | 含义 |
|------|------|------|
| ≥60 | **高反弹潜力** | 可观察反弹，关注入场时机 |
| 40-59 | **中等反弹潜力** | 反弹可能，谨慎观察 |
| <40 | **低反弹潜力** | 可能继续下跌，不宜抄底 |

### 涉及文件

| 文件 | 改动 |
|------|------|
| `scan-dump-risk.mjs` | 新增 `calcReboundPotential` 函数计算反弹潜力分；返回结果增加 `reboundScore`/`reboundLevel` 字段 |
| `server.mjs` | `runDumpAlertPush` 推送表格增加"反弹"列；高反弹潜力币种用绿色标注与红色风险分对比 |

### 输出格式

暴跌推送表格增加"反弹"列：

```
| 币种 | 币价  | 8am    | 24h    | 风险 | 反弹 | 市值 | 风险标签        |
|------|-------|--------|--------|------|------|------|----------------|
| EVAA | $0.62 | -68.0% | -32.0% | 8🔴  | 75🟢 | $50M | 高危·RSI超卖   |
```

高反弹潜力（≥60）的币种在推送标题中额外标注：
```
🚨 暴跌预警 · 3 个 · ⚡ 1 个高反弹潜力
```

### 验收标准

- [ ] 暴跌推送表格新增"反弹"列，显示反弹潜力分和等级颜色
- [ ] EVAAUSDT 反弹潜力分 ≥ 60（RSI 超卖+跌幅深度+大户偏多+散户偏空+背离）
- [ ] 高反弹潜力币种在推送标题中标注数量
- [ ] 反弹潜力评分不受风险分影响，两者独立计算
- [ ] 无 RSI/多空比数据的币种，只按跌幅深度评分，不报错
