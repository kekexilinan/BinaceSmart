## 简介
本仓库实现了一个面向币安合约的"聪明钱"监控与报警通知系统，覆盖价格预警、技术指标报警、大户行为监控与自定义条件触发机制。系统提供飞书推送、浏览器弹窗与声音提醒等通知渠道，并内置智能降噪、误报过滤与历史记录能力。同时支持持仓健康监控与操作清单生成，便于用户进行策略复盘与决策辅助。

**更新** 新增反弹机会高亮展示和反弹潜力评分功能，通过独立的急跌反弹观察区块和多维度评分模型，显著提升暴跌后反弹机会的识别能力和可视化效果。

### 反弹机会高亮展示与潜力评分
**新增** 系统实现了完整的反弹机会识别和展示功能，包括独立的高亮区块和多维度的反弹潜力评分。

#### 反弹潜力评分模型
- **评分因子**：基于 RSI 超卖、跌幅深度、大户偏多、散户偏空、大户散户背离、缩量止跌、下影线长等多个因子加权计算，评分范围 0-100。
- **等级划分**：≥60 为高反弹潜力（🟢），40-59 为中等反弹潜力（🟡），<40 为低反弹潜力。
- **背离检测**：当大户多空比 > 1.0 且散户多空比 < 0.9，且背离度 ≥ 0.25 时触发背离信号。

#### 急跌反弹观察高亮
- **触发条件**：当 decision 输出的 action 组中包含 rebound_watch 视图且该币种 |change24h| ≥ 15% 时触发。
- **显示位置**：在推送卡片顶部（时间标题之后、固定监控之前）插入独立高亮区块。
- **内容格式**：包含跌幅、当前价格、聪明钱偏多情况、大户抄底背离等信息。

```mermaid

A["暴跌风险评估"] --> B["计算反弹潜力评分"]
```

## 故障排查指南
- 飞书推送失败
  - 检查 FEISHU_WEBHOOK 是否配置正确。
  - 查看返回码与 msg，区分频控与业务错误；必要时调整推送频率或分卡发送。
- 币安 API 异常
  - 检查代理节点与网络连通性；参考 proxy-setup.mjs 的代理配置。
  - 若出现 418/429/403，遵循熔断退避策略，稍后重试。
- 端口占用
  - 使用 dev-restart.mjs 自动清理旧进程；或手动终止占用端口的进程。
- 持仓健康推送未触发
  - 确认 POSITION_HEALTH_ENABLED 与 watchSymbols 配置。
  - 检查 urgentCheckMin 与 urgentCooldownMin 是否导致冷却期过长。
- **新增** 反弹潜力评分异常
  - 检查 RSI 计算所需的 K 线数据是否完整。
  - 验证大户散户多空比数据源是否正常返回。
  - 确认背离阈值配置 SMART_TREND_DIVERGENCE_THRESHOLD 是否合理。
  - 检查 REBOUND_HIGHLIGHT_CHANGE_PCT 环境变量是否正确设置。

## 结论
本系统围绕"聪明钱"数据构建了从数据采集、信号分析、趋势研判到操作清单的全链路能力，并通过飞书推送与本地通知形成闭环。通过市值过滤、TradFi 排除、限流熔断与冷却期等机制，有效降低了误报与噪声。

### 反弹机会功能开发指南
**新增** 反弹机会功能的开发和集成指南。

- 在 smart-trend-monitor.mjs 中计算 divergence = whaleRatio - globalRatio

- 在 smart-trend-decision.mjs 中收集 rebound_watch 信号且跌幅超过阈值的币种

- 支持合成数据注入和多种推送格式的测试
