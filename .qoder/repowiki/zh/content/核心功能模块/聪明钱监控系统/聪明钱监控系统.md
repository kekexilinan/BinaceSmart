## 简介
本系统为基于币安合约 API 的"聪明钱（Smart Money）"监控工具，提供 Web 面板与终端两种使用方式。围绕大户与鲸鱼账户行为，构建多空比率、持仓量变化、主动买卖量等核心指标，并结合资金费率、趋势形态与风险评分，输出可操作的信号与推送。

- 功能要点
  - K 线图 + RSI + 十字光标
  - 大户多空比（账户维度/持仓维度）、全网多空比、持仓量变化、主动买卖量
  - **全新**：全面的背离检测系统，智能识别"大户抄底/散户恐慌"反转信号
  - **重大升级**：增强的决策引擎，包含完整的行动剧本和场景分类系统
  - **新增**：7种标准化交易场景，每种场景提供详细操作指导
  - **增强**：反弹监控信号分类系统与评分机制，背离条件下敏感度提升
  - **新增**：反弹潜力评分系统，多维度评估暴跌后的反弹机会
  - **优化**：急跌反弹观察区块独立高亮展示，避免被淹没在大量数据中
  - **完善**：pump risk和distribution警告机制，强化风险管理
  - **新增**：鲸鱼与全网比率跟踪功能，支持whaleRatio和globalRatio指标计算
  - **新增**：1小时和8am变化监控，用于市场反转或趋势延续的早期预警信号
  - 信号摘要：大户翻多/翻空、聪明钱抄底信号、资金费率状态
  - 报警系统与飞书推送
  - 市值过滤（默认只监控市值 ≤ 80 亿美元的币种）
  - 榜单汇总去重、8am分档计分、来源追踪标签

- 快速开始
  - 环境要求：Node.js ≥ 20
  - Web 面板：pnpm dev:restart → http://localhost:3388
  - 终端版：node smart-money.mjs SLXUSDT 60

## 项目结构

### **重大升级**：增强的决策引擎与行动剧本系统

#### 行动剧本（Action Playbook）架构
系统实现了完整的行动剧本系统，为每种交易场景提供标准化的操作指导：

- **7种标准化场景分类**：
  - `trend_long`：趋势做多候选（顺势，高优先级）
  - `rebound_watch`：超跌反弹观察（反转，中等优先级）
  - `accumulation`：聪明钱吸筹观察（顺势，中等优先级）
  - `pump_risk`：冲高风险观察（反转，高优先级）
  - `downtrend_risk`：下跌延续风险（顺势，高优先级）
  - `distribution`：聪明钱派发风险（反转，中等优先级）
  - `neutral_watch`：观望（中性，低优先级）

- **每场景包含完整指导要素**：
  - `scene`：场景类型（顺势/反转/观望）
  - `action`：具体操作建议
  - `avoid`：风险提示和避免事项
  - `waitFor`：等待确认条件
  - `urgency`：紧急程度（high/medium/low）

#### 场景分类算法
决策引擎根据市场数据和聪明钱行为自动分类交易场景：

### 背离检测与反弹监控

#### 背离检测算法
系统实现了全面的大户 vs 散户多空比背离检测功能，这是反弹机会识别的核心机制：

- **背离度计算公式**：`背离度 = 大户多空比 - 全网多空比`
- **触发条件**：当 `背离度 ≥ 0.25` 且 `大户多空比 > 1.0` 且 `全网多空比 < 0.9` 时判定为"大户抄底/散户恐慌"背离信号
- **配置参数**：阈值可通过环境变量 `SMART_TREND_DIVERGENCE_THRESHOLD` 配置，默认 0.25

#### 反弹监控信号增强
当检测到背离条件时，系统会触发更敏感的反弹监控信号：

- **敏感阈值调整**：有背离信号时，跌幅 `-5%` 即触发 `rebound_watch` 信号（正常需 `-10%`）
- **评分加成**：背离信号在评分机制中获得额外 `+12` 分加分
- **高亮展示**：急跌反弹观察区块在推送卡片中独立高亮显示

```mermaid

A["数据采集"] --> B["计算大户vs散户背离度"]

C --> |否| E["正常监控模式"]
D --> F["rebound_watch信号阈值<br/>从-10%降至-5%"]
```

### 反弹潜力评分系统

#### 评分维度
暴跌推送中新增反弹潜力评分系统，多维度评估反弹机会：

- **RSI6超卖检测**：RSI6 < 20得25分，RSI6 < 30得15分
- **24h跌幅深度**：暴跌-50%得30分，大跌-30%得20分
- **大户偏多加分**：大户多空比 > 1.0得15分
- **散户偏空加分**：全网多空比 < 0.8得10分
- **背离信号加分**：背离度 ≥ 0.25得15分
- **缩量止跌检测**：最近1h成交量 < 前3h均值50%得10分
- **下影线长度检测**：下影线占比 < 30%得10分

#### 评级标准
- **高分（≥60）**：🟢 高反弹潜力 - 可观察反弹，关注入场时机
- **中分（40-59）**：🟡 中等反弹潜力 - 反弹可能，谨慎观察  
- **低分（<40）**：普通反弹潜力 - 可能继续下跌，不宜抄底

- 端口占用
  - 启动报 EADDRINUSE 时，使用 dev:restart 自动清理旧进程，或手动 kill 占用端口进程
- 代理与地区限制
  - 设置 HTTPS_PROXY/HTTP_PROXY，Windows 下优先 curl；若出现地区限制错误，检查节点可用性

  - 调整 MAX_RANKING_MARKET_CAP 或设为 0 关闭过滤

### **重大升级**：增强的决策引擎与场景分类解读

#### 行动剧本系统详解
系统为每种交易场景提供了标准化的操作指导：

- **趋势做多（trend_long）**
  - 场景：顺势
  - 操作：可轻仓顺势做多
  - 避免：勿重仓追高
  - 等待：回踩不破 + 聪明钱继续偏多
  - 紧急程度：高

- **反弹观察（rebound_watch）**
  - 场景：反转
  - 操作：等价格止跌确认后再考虑入场
  - 避免：下跌途中抄底
  - 等待：跌幅收窄 + 聪明钱由空转多
  - 紧急程度：中等

- **吸筹观察（accumulation）**
  - 场景：顺势
  - 操作：观察吸筹，等待突破确认
  - 避免：单次重仓
  - 等待：突破 + 量变
  - 紧急程度：中等

- **冲高风险（pump_risk）** ⚠️
  - 场景：反转
  - 操作：禁止追多；等冲高回落再考虑做空
  - 避免：暴涨中抄底或追多
  - 等待：量能萎缩 + 聪明钱持续偏空
  - 紧急程度：高

- **派发风险（distribution）** ⚠️
  - 场景：反转
  - 操作：聪明钱派发，减持多单
  - 避免：勿加仓
  - 等待：跌破支撑
  - 紧急程度：中等
