- 所有 Node 脚本统一采用 ESM import，并用 `dirname(fileURLToPath(import.meta.url))` 解析 `__dirname` 定位相对路径。
- 入口函数封装为 `async function main()` 并在末尾以 `main().catch(e => { console.error(...); process.exit(1); })` 形式处理未捕获异常。
- Windows 平台通过 `cmd /c` 或 `wscript.exe` 包装实现无控制台窗口后台运行，PowerShell 侧统一设置 `$ErrorActionPreference = 'Stop'` 配合 try/catch 控制错误传播。
- 环境变量优先从同级 `.env` 文件中逐行匹配 `KEY=VALUE` 注入到 `process.env`，缺失时回退到默认值或抛出明确错误。
