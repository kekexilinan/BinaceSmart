- 每个扫描器顶部先 `import { setupProxyFromEnv } from './proxy-setup.mjs'` 并立即调用一次，再加载业务逻辑，确保代理生效。
- 对外导出函数一律采用 `{ limit, minScore/minRiskScore, concurrency, onProgress } = {}` 的具名参数对象模式，默认值集中在签名处声明。
- 并发遍历统一复用内部 `pmap(items, fn, concurrency)` 实现，worker 数通过参数控制，捕获异常后以 `null` 占位避免中断整体扫描。
- 候选标的均从 `fapi.bapi/v1/ticker/24hr` 获取并按 `quoteVolume` 排序切片，且过滤 `symbol.endsWith('USDT')`，部分扫描叠加 `isTradFiSymbol` 排除。
- 技术指标计算（MA/RSI/MACD/回撤）均以纯函数形式接收 closes/highs/lows 数组，不持有状态，便于单元测试与跨扫描复用。
- 评分型扫描返回结构包含 `score`/`signals`/`detail` 字段，其中 `detail` 用 `[x/y] tag1 tag2 ...` 格式汇总，供上层直接渲染。
