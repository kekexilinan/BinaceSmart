根目录作为跨子模块的编排层，通过 `package.json` 的 npm scripts 与 `ecosystem.config.cjs`（PM2）把五个子模块串联：
- 启动契约：`server.mjs`（http_server）由 PM2 fork 模式常驻，暴露 `/api/*` 代理币安合约 API 并承载前端页面；顶层 `.mjs` 脚本（smart-money、pump-smart-alert、strategy-review、tradfi-symbol-filter、whale-history）作为一次性或定时任务调用 signal_scanners / smart_trend / position_health 等子模块。
- 配置契约：所有子模块统一从 `.env` 读取 `FEISHU_WEBHOOK`、`CMC_API_KEY`、`MAX_MARKET_CAP_USD`、`PORT`、`STABLE_*` 等环境变量，形成跨子模块的配置边界。
- 部署编排：`ecosystem.config.cjs` 定义单一 PM2 app（binace-smart），配合 `scripts/` 下的 Windows PowerShell 服务安装/停止脚本以及 `dev-restart.mjs` 端口热重启流程，实现 Windows/Linux 双平台一致拉起。
- 数据源收敛：各子模块均依赖同一套币安合约 REST API（fapi.binance.com）与可选的 CoinMarketCap/CoinGecko 市值接口，避免各自重复封装。
