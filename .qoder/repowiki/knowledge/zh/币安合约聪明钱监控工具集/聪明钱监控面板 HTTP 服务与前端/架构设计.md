单入口 `server.mjs` 通过 shebang 直接以 `node server.mjs` 启动，职责分层如下：
- 请求路由层：`createServer` + 按路径前缀分发到 `handleGainersSince8am`/`handleAPI`/`collectPredictionSnapshot` 等 handler，静态文件由 MIME 表映射 `index.html`。
- 外部依赖封装：`proxy-setup.mjs` 提供 `fetchJson`（Windows+代理时走 `curl.exe`）和 `setupProxyFromEnv`，统一处理 `HTTPS_PROXY`/`HTTP_PROXY` 环境变量；所有对 Binance FAPI 的请求经 `proxyBinance` 重试 + 退避。
- 业务逻辑层：通过 ESM import 组合 `scan-stable.mjs`、`scan-smart-signal.mjs`、`scan-dump-risk.mjs`、`whale-history.mjs`、`strategy-review.mjs`、`position-health-monitor.mjs`、`smart-trend-monitor.mjs` 等扫描/策略模块。
- 调度器：`startStablePushScheduler`、`startPredictionSnapshotScheduler`、`startPositionHealthScheduler` 等基于 `setTimeout` 的上海时间定时任务，驱动飞书卡片推送。
- 缓存：ticker24hr 并发去重缓存 (`ticker24hrCache`)、市值缓存 (`mcCache`，优先 CMC API，回退 CoinGecko)、8am 基准价缓存 (`baseline8amCache`)。
- 前端：`index.html` 为自包含 SPA，内嵌 CSS + `<script>`，通过 `/api/*` 轮询后端并渲染 Canvas K 线、RSI、策略面板、模拟交易与报警弹窗。
