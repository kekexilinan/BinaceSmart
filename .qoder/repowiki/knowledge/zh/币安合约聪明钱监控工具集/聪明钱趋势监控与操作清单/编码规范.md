- 对外部副作用（飞书推送、鲸鱼历史、榜单数据）一律通过 deps 对象注入，模块自身不直接 import 业务 API，便于测试与替换。
- 所有时间窗口与日期切分统一用 Intl.DateTimeFormat('en-US', { timeZone: 'Asia/Shanghai' }) 获取 parts，再以 `${year}-${month}-${day}` 作为 dateKey 进行跨进程一致性比较。
- 状态持久化采用 Promise 队列（saveQueue / decisionSaveQueue）串行写入 data/*.json，避免并发竞态，失败时 catch 吞错保证主流程健壮。
- 字符串常量集中放在 smart-trend-labels.mjs 导出（RATIO_WARN_PCT、DIGEST_TABLE_COLUMNS、formatTopMoveItem 等），decision 与 monitor 只消费不重复定义阈值。
- 所有数值字段在参与计算前通过 num()/parseFloat 归一化为 Number，缺失值一律返回 null 并用 ?? 短路，禁止 NaN 参与排序与比较。
- 表格渲染统一产出 `{ tag: 'table', columns, rows, page_size, row_height, freeze_first_column }` 元素数组，配合 `buildDigestTableRows` 复用列布局。
