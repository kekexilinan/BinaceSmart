模块由四个职责清晰的 ESM 文件组成，依赖方向单向：labels → decision → monitor + watchlist。
- smart-trend-labels.mjs：纯展示层，导出 RATIO_WARN_PCT、ratioDeltaDisplay / priceCellDisplay / buildDigestTableRows 等格式化函数与 DIGEST_TABLE_COLUMNS 列定义，被 decision 和 monitor 共同消费。
- smart-trend-watchlist.mjs：动态币种池维护者，通过 deps.getGainers24h/getLosers24h/getTopByVolume/scanRightSide 拉取 TopN 涨跌榜、右侧交易与成交额 TopN，按上海时间 08:00（或 24h TTL）刷新并持久化到 data/smart-trend-watchlist.json；提供 getWatchSymbols()/getWatchlistGroups() 供 monitor 消费，并在 onWatchlistUpdated 回调中通知 monitor 清理状态。
- smart-trend-decision.mjs：决策引擎，mergeRowsBySymbol 合并多榜单去重后，classifyView/calcScore/resolveContinuity 对每个币种打分并判定 trend_long/rebound_watch/accumulation/pump_risk/downtrend_risk/distribution/neutral_watch 七种视图，结合 previousState 做连续性追踪（strengthened/continued/weakened/reversal_watch/reversed/new），输出 action/watch/invalidated 三组候选及 nextState 供持久化。
- smart-trend-monitor.mjs：调度与编排入口，initSmartTrendMonitor 注入 deps（feishu/webhook、whale-history、board 数据源），runSmartTrendPush 每整点扫描 watchlist 所有币种，attachRatio8amDeltas 基于 whale bulk 历史补齐 8am 基准，recordHints8amCounts 累计当日 1h±5% 计分，computeMarketOutlook 汇总多空倾向，再调用 buildSmartTrendDecision/buildSmartTrendDecisionElements 生成「操作清单」卡片，并通过 mergeCards 开关选择单张合并推送或多卡分板推送；state 与 decision state 分别持久化到 data/smart-trend-state.json 与 data/smart-trend-decision-state.json，同时写入 push mock 快照到 data/smart-trend-push-mock.json 用于调试。
- 外部边界：monitor 通过 deps 接口反向调用 scan-smart-signal.mjs 的 fetchSmartSignal/analyzeSmartSignal 以及 whale-history.mjs 的 registerActiveSymbol/getWhaleHistoryBulk，watchlist 通过 deps.registerActiveSymbol 注册活跃币种，形成以本模块为编排中心、向外暴露 init/start/run 钩子的松耦合结构。
